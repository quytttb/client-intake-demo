## Nội dung

| Section | Mô tả |
|---------|-------|
| **Landing** | Giới thiệu dịch vụ automation: bot nhận khách, đặt lịch, phân loại nhu cầu cho shop/freelancer |
| **Demo Chat** | Widget chat mô phỏng bot nhận khách + panel "Góc nhìn chủ shop" real-time |
| **Dự án** | Hệ thống Quản lý Đơn hàng Đa kênh (Shopee, Lazada, TikTok Shop, Website) — kiến trúc n8n + Telegram alert |

## Tech Stack

- **Framework:** Next.js 15 (static export)
- **Hosting:** GitHub Pages
- **CI/CD:** GitHub Actions
- **Styling:** Tailwind CSS
- **Dự án thực tế:** n8n, Python, Telegram Bot API, REST APIs

## Chạy local

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static export → out/
```

## Deploy

Push lên `main` → GitHub Actions tự build & deploy lên GitHub Pages.
